# Home Finance Webapp

App simples para Eduardo e Camila acompanharem finanças da casa.

## Stack
- HTML, CSS e JavaScript puro
- Supabase será usado depois como backend/banco
- Sem autenticação por enquanto
- Mobile-first
- Hospedagem em subdomínio da Hostinger

## Objetivo da V1
Criar um dashboard doméstico simples, bonito e responsivo.

## Estado atual
Existe um `index.html` com:
- Card de despesas fixas
- Total mensal previsto: $5,369.00
- Lista de despesas fixa
- Mês dinâmico no canto superior direito
- Botão para ocultar/expandir a lista

## Regras importantes
- Não adicionar frameworks.
- Não adicionar React.
- Não adicionar login.
- Não alterar os valores sem pedir.
- Manter tudo responsivo para celular.
- Priorizar UI limpa, moderna e fácil de usar.
- Código simples de manter.
